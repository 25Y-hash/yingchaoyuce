# 英超预测（my-h5）

一个英超联赛预测与数据展示的 Web 应用。前端用 Vue 3 + Vite + TypeScript + Element Plus 构建，后端用 Spring Boot 3 + MySQL + MyBatis-Plus 提供接口。

---

## 功能模块

### 前端页面

- **首页**：以「1 大 2 小」的图片卡片布局，作为三个预测入口的导航。
- **精彩时刻**：B 站风格视频流，每页「1 大 6 小」，点击跳转 B 站，支持悬停放大与标题变色。
- **观众预测**：
  - 排行榜：前三名领奖台展示，第 4~20 名列表展示票数与占比。
  - 评论区：支持按队伍筛选，登录用户可发表评论，点击「展开剩余 N 条」模拟大数据量。
- **专家预测**：展示专家观点与支持的球队，卡片左侧用球队主色描边。
- **AI 预测**：左右滑动切换球队，顶部下拉框快速定位；展示六维雷达图、夺冠概率与球星照片。
- **历史回顾**：历届战绩表格（支持正倒序切换）与英超历届夺冠次数柱状图。
- **积分榜**：按欧冠区、欧联区、降级区分组展示，点击任意一行弹出该队详情。
- **导航栏**：支持横向滚动（手机端），当前页对应项换成图片，整体宋体加粗。

### 后端接口

- 用户注册 / 登录（JWT 鉴权）
- 积分榜、球队预测、专家解析、历史战绩
- 观众投票排行榜、观众评论（分页、发表评论）

## 技术栈

### 前端

| 技术 | 说明 |
|---|---|
| Vue 3 | 组合式 API（`<script setup>`） |
| Vite | 构建与开发服务器，配置 `/api` 代理 |
| TypeScript | 类型检查 |
| Vue Router | 路由（Hash 模式，便于打包 App） |
| Pinia | 状态管理 |
| Element Plus | UI 组件库 |
| 原生 CSS | Flex / Grid 布局、`@media` 响应式、`::before` 底图、毛玻璃 |

### 后端

| 技术 | 说明 |
|---|---|
| Spring Boot 3 | 后端框架 |
| Java 17 | 后端语言 |
| MySQL 8 | 数据库 |
| MyBatis-Plus | ORM，单表 CRUD 与分页 |
| Flyway | 数据库版本管理，启动时自动建表与插数据 |
| JWT | 登录鉴权（拦截器 + ThreadLocal） |
| Swagger / Knife4j | 接口文档 |
